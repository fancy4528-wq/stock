# ADR-0009: 监控采用三级漏斗，规则层零 LLM 成本

- 状态: 已接受
- 日期: 2026-08-31
- 相关: [15-monitoring-alerts](../15-monitoring-alerts.md), [16-token-economics](../16-token-economics.md)

## 背景

需要盘中监控持仓与市场消息，在判断持仓需调整时主动推送。

朴素方案：把每条新闻和行情变化交给 LLM 判断"这是否影响持仓"。

问题：A 股每日约 2000 条新闻。若逐条调用 LLM，成本远超个人项目可承受范围。且随市场波动，极端行情下新闻量可能是平时的 5-10 倍。

## 决策

**三级漏斗，L1 完全不调 LLM。**

```
L1  规则层（零成本）   全部 ~2000 条  → 通过率 ~1%
L2  小模型分诊         ~50 条        → 升级率 ~20%
L3  大模型深度分析     ~6-10 次
```

配套硬约束：

1. **A 类价格触发器、B 类风控触发器完全不调 LLM**（架构测试强制）
2. **L1 规则层不 import `agents` 模块**（架构测试强制）
3. **预算耗尽时降级为 L1，关键告警仍工作**（有测试）
4. L3 复用既有 `StockAgent`，不新建 Agent

## 理由

**成本降低两个数量级。** 从"不可行"变成"每日 $0.15"。

**最关键的监控恰好不需要 LLM。** 止损线、涨跌停、停牌、组合回撤——这些都是数值比较，规则能完美处理。LLM 在这里不增加任何价值。

**实体匹配靠词典比靠 LLM 更可靠。** "这条新闻提到了贵州茅台吗"是字符串匹配问题，不是理解问题。预建别名词典（简称/全称/别称/产品名）准确率高于 LLM 且免费。

**公告类型是结构化字段。** 交易所公告有类型标签，"立案调查"、"业绩预告-预亏"这类关键类型可以纯规则识别。而这些恰恰是最需要推送的。

**降级路径保证系统韧性。** 预算耗尽时，一个只有规则层的监控系统仍然有实质价值。如果监控完全依赖 LLM，预算耗尽等于功能失效。

**先做规则层能验证需求。** P2a 完全零成本，可以先验证"触发器是否有用、频率是否合适、用户是否会看"。如果 P2a 的推送有用率低于 40%，说明触发器设计有问题，此时加 LLM 只会放大问题并花钱。

## 被否决的方案

| 方案 | 否决理由 |
|---|---|
| 每条新闻调 LLM 判断相关性 | 成本不可接受（估算日均 $10+） |
| 只用 LLM，不做规则层 | 预算耗尽时功能完全失效；且规则能做的事 LLM 做得更贵不更好 |
| 只用规则，不用 LLM | 无法处理"这条新闻对该公司意味着什么"这类需要理解的判断 |
| 两级漏斗（规则 → 大模型） | 中间缺少廉价分诊层，L1 通过的 50 条直接给大模型仍然贵 |
| 用 embedding 相似度替代 L2 | 相似度不能判断影响方向和紧急度 |
| 新建 MonitorAgent 做 L3 | 与 `StockAgent` 能力重复；新建意味着新 prompt、新测试、新评估 |
| 全市场盘中监控 | 处理量再放大 100 倍，成本不可行 |

## 后果

**正面**：
- 日均监控成本 < $0.30
- 关键告警不受预算影响
- P2a 可独立交付且零成本
- 即使 LLM 层被证明无价值，规则层仍有独立价值

**负面**：
- 需要人工维护实体别名词典和关键词分级表
- 词典/关键词表的覆盖不足会导致漏报
- L1 规则较机械，可能过滤掉需要理解才能发现的重要新闻
- 三层结构增加实现复杂度

**必须接受的代价**：L1 会漏掉一些"字面上不提及持仓但实际有影响"的新闻（如竞争对手的重大进展）。缓解手段是 L1 同时匹配行业和上下游，但无法做到完全覆盖。

## 配套的架构约束

```python
FORBIDDEN += [
    ("monitor.triggers.price",  ["agents", "monitor.funnel.l2_triage",
                                 "monitor.funnel.l3_analysis"]),
    ("monitor.triggers.risk",   ["agents", "monitor.funnel.l2_triage",
                                 "monitor.funnel.l3_analysis"]),
    ("monitor.funnel.l1_rules", ["agents"]),
]

def test_monitor_works_without_budget():
    """预算为零时，止损告警仍应触发且成本为 0。"""
    engine = MonitorEngine(budget=MonitorBudget(daily_usd_limit=0.0))
    alerts = engine.run(state_with_stop_loss_breach)
    assert any(a.trigger_codes == ["PX_STOP_LOSS"] for a in alerts)
    assert all(a.cost_usd == 0 for a in alerts)
```

## 复审条件

- 若 L1 通过率持续 > 10%，说明规则设计有问题，需审查关键词表与别名词典
- 若 L2 判断准确率 < 85%，考虑换模型或增大上下文
- 若本地小模型评估达标，L2 可完全本地化（成本降为零）
- 若 Gate 2b 显示加 LLM 后推送有用率未提升，回退到纯规则监控
